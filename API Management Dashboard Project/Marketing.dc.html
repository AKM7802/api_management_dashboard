Questions
Does it work with non-LLM APIs? {{ i0 }}
Yes — any HTTP API that authenticates via bearer or api-key header. Token & cost charts simply stay hidden until a response reports token usage.
Is there billing or quotas? {{ i1 }}
No. Cost is a convenience estimate from a built-in price table — there's no invoicing, payment, or plan system.
How are keys stored? {{ i2 }}
Encrypted at rest with AES (Fernet) under an operator-controlled key. Only the last four characters are ever displayed again.
